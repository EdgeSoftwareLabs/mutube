# YouTube + for Samsung Tizen TVs

Two ways to ship it. Both load TizenTube (ad-block, SponsorBlock, its
long-press menu) followed by `youtube-plus.js`, which adds **Not interested**
and **Don't recommend channel** to every Home tile's long-press menu.

## A. TizenBrew module (recommended) - ready to build, untested on a TV

[TizenBrew](https://github.com/reisxd/TizenBrew) fetches modules from jsDelivr
(`npm/<package>` or `gh/<user>/<repo>`), reads `package.json`
(`packageType: "mods"`, `websiteURL`, `main`, `serviceFile`) and evaluates
`main` inside the YouTube TV page.

```bash
python3 platforms/build_platforms.py tizen-module
# -> platforms/tizen/module/dist/userScript.js  (TizenTube 1.15.2 + youtube-plus.js)
# -> platforms/tizen/module/dist/service.js     (TizenTube's service, unchanged)
```

Publish it, either:
- **GitHub**: commit `platforms/tizen/module/dist` (it is git-ignored by
  default: `git add -f`), push the branch, then in TizenBrew add the module
  `gh/mistermassacre/mutube@youtube-plus/platforms/tizen/module`; or
- **npm**: `cd platforms/tizen/module && npm publish` (pick a package name you
  own), then add `npm/<name>` in TizenBrew.

The bundle contains TizenTube, which is GPL-3.0: publish it under GPL-3.0 and
link to TizenTube's source.

## B. Standalone .wgt "YouTube +" (no TizenBrew, no CDN for the script)

TizenTube's standalone app (`standalone/` at the TizenTube commit whose
`package.json` is 1.15.2), rebranded "YouTube +" with our icons and its own ids
(`YTPlus0001.YouTubePlus`), so it installs next to TizenTube. The user script
(TizenTube 1.15.2 from npm + `youtube-plus.js`, including the settings rebrand)
is compiled into the widget's service, which serves it at `/__ytplus/userScript.js`
on every path TizenTube uses: the local proxy (`http://localhost:8100/tv`), the
native-Cobalt MITM proxy (same origin, `https://www.youtube.com/__ytplus/...`) and
the developer-mode CDP injector. Nothing has to be pushed or published for it to
run. `build_platforms.py` applies each patch exactly once or fails.

```bash
git clone https://github.com/reisxd/TizenTube /tmp/TizenTube    # package.json 1.15.2
platforms/tizen/standalone/build.sh /tmp/TizenTube             # -> build/tizen-standalone/pkg (unsigned)
tizen package -t wgt -s <Samsung certificate profile> -- build/tizen-standalone/pkg
tizen install -n "YouTube +.wgt" -s <tv-ip>:26101 -- build/tizen-standalone/pkg
```

Needs Tizen Studio (CLI + TV extension), a Samsung certificate profile whose
distributor certificate lists the TV's DUID, and the TV in Developer Mode with
the Mac's IP as developer IP. The widget includes TizenTube's code: GPL-3.0
(its `LICENSE.TizenTube` and our `NOTICE` ship inside the .wgt).
Icons: `icon.png` (512x512) and `icon_16b9.png` (1920x1080), generated by
`icons/generate_icons.py`.
