# Apple TV (tvOS) assets

`Assets.xcassets/` holds the YouTube + layered app icon (Front + Back layers,
400x240 @1x/@2x and 1280x768 App Store size) and the Top Shelf images
(1920x720 and 2320x720, @1x/@2x), generated by `icons/generate_icons.py`.

`make ICONS=1` (or `patcher.py --tvos-icons platforms/tvos/Assets.xcassets`)
compiles this catalog with `xcrun actool` and replaces the IPA's `Assets.car`,
merging the `CFBundleIcons` / `TVTopShelfImage` keys actool emits into
Info.plist. This is **experimental and untested**: asset catalogs cannot be
merged, so the patcher first compares rendition names (`xcrun assetutil
--info`) and refuses if the original `Assets.car` contains anything the icon
catalog lacks (launch images, in-app artwork...). Use `--force-icons` only if
you have checked that the missing renditions are unused.
