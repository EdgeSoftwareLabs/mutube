# Apple TV (tvOS) assets

`Assets.xcassets/` is a drop-in replacement for the `Assets.car` in the
YouTube 4.54.01 tvOS IPA, generated by `icons/generate_icons.py`. That car
(`xcrun assetutil --info`) contains only four assets, and Info.plist refers
to them by name, so ours uses the same names and Info.plist is not touched:

| Asset | Contents |
|---|---|
| `AppIconSmall` | 2-layer image stack (Front logo, Back white), 400x240 @1x / 800x480 @2x |
| `TopShelfImage` | 1920x720 @1x |
| `Top Shelf Image Wide` | 2320x720 @1x / 4640x1440 @2x |
| `LaunchImage` | 1920x1080 @1x / 3840x2160 @2x |

`make ICONS=1` (or `patcher.py --tvos-icons platforms/tvos/Assets.xcassets`)
compiles it with `xcrun actool` and replaces `Assets.car`. The patcher refuses
if the original car has any rendition name the new one lacks
(`--force-icons` overrides). Checked on the 4.54.01 MuTube build: the
compiled car has the same rendition names, types, sizes, scales and platform
(atv 13.0) as the original. Not yet seen on a TV screen.
