# YouTube + in a desktop browser

`youtube-plus.user.js` (generated by `python3 platforms/build_platforms.py web`)
is a Tampermonkey / Violentmonkey user script for **youtube.com/tv**, the same
leanback client the TVs use. It adds **Not interested** and **Don't recommend
channel** to the long-press (hold Enter) menu of every Home tile.

Install: open the raw file in a browser with Tampermonkey, or create a new
script and paste it.

Notes:
- youtube.com/tv redirects normal desktop browsers to youtube.com. Use a TV
  user agent (for example a user-agent switcher with
  `Mozilla/5.0 (SMART-TV; Linux; Tizen 6.0) AppleWebKit/537.36 (KHTML, like Gecko) 85.0.4183.93/6.0 TV Safari/537.36`).
- Regular desktop youtube.com already shows both items in each video's
  three-dot menu, so the script does nothing there.
- Works alone (it builds a small menu when no TizenTube menu exists) or after
  TizenTube's user script.
- `icons/` holds a favicon, PNG icons and a web manifest if you wrap
  youtube.com/tv as a kiosk/PWA.
